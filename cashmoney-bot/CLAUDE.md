# CashMoney.bot

## What this is
AI-powered money tools SaaS. 5 tools under one subscription that find hidden money opportunities.

## Domain
cashmoney.bot (on Cloudflare)

## Tools
1. TCPA Claim Generator — spam call violations, $500-$1,500 per call
2. Domain Sniper — expired e-commerce domains from bankruptcy court
3. Credit Dispute AI — auto-generate FCRA dispute letters
4. ADA Site Scanner — website accessibility violations, $3-10K settlements
5. Demand Letter Writer — AI-drafted legal demand letters

## Pricing
- Free: Limited access
- Pro $29/mo: Unlimited everything
- Agency $99/mo: Bulk + API + white-label

## Design direction
Premium dark theme. Neon green (#00ff88) accent. Inspired by eonixenergy.com and wearebreakfast.com. Custom preloader, scroll animations, kinetic typography, grain texture, glassmorphism cards, particle effects. Should look like a $50K website.

## Deploy
Cloudflare Pages. Output directory: `public/`

## Revenue strategy
Animated stickman reels (like @Mrstickmantkk style) → CashMoney.bot branding at end → run as FB/IG ads → drive to landing page → email capture → convert to $29/mo subscribers
