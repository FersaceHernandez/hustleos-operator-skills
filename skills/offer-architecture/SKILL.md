# Offer Architecture

Use this skill to turn vague value into a clean offer.

## Trigger on requests like

- build this offer
- price this service
- turn this into packages
- help me position this
- what should the tiers be
- how do I make this easier to sell

## Goal

Produce an offer that is:
- easy to explain
- easy to buy
- easy to deliver
- anchored in an obvious result

## Workflow

1. Define the buyer.
2. Define the painful before state.
3. Define the promised after state.
4. Name the mechanism or delivery style.
5. Turn the work into 1 to 3 clean packages.
6. Remove anything that makes fulfillment messy.
7. Add one CTA and one next step.

## Output format

Return:
- **Core offer**
- **Who it is for**
- **Problem it solves**
- **Packages and pricing**
- **Guarantee or risk reversal**
- **Why it should convert**
- **Next move**

## Rules

- Sell outcomes, not busywork.
- Fewer tiers beat too many choices.
- Avoid custom-sounding fulfillment unless the user explicitly wants high-touch work.
- If the offer is weak, say so and fix the promise or target market.
