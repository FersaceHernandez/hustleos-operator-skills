# Sales Call Close

Use this skill when the user needs a call that actually closes.

## Best for

- discovery calls
- zoom closes
- service sales
- agency offers
- local business sales
- intake calls with a paid next step

## Call structure

1. Frame the call.
2. Diagnose the pain.
3. Make the cost of inaction obvious.
4. Show the path.
5. Handle objections.
6. Ask for the close.

## Output format

Return:
- **Opening frame**
- **Discovery questions**
- **Pain amplification**
- **Offer transition**
- **Close ask**
- **Objection responses**
- **Follow-up message**

## Rules

- Do not overteach before the close.
- Ask questions that expose urgency, money, and consequences.
- Proof beats theory.
- If there is a live demo or audit, use it as the turning point.
- End with a direct ask, not vague next steps.
