# Reel Production

Use this skill to turn raw thoughts into something postable.

## Best for

- 15-45 second reels
- founder/operator talking head videos
- ad-style organic content
- educational rants
- before/after proof content
- AI-assisted B-roll workflows

## Workflow

1. Find the angle.
   - pain
   - mistake
   - contrarian take
   - result
   - transformation
2. Write the hook first.
3. Build a script with short spoken lines.
4. Match each beat with one visual.
5. End with a CTA or punchline.

## Default output

Return these sections:
- **Hook**
- **Script**
- **Shot list**
- **B-roll prompts**
- **Caption**

## Writing rules

- Start with tension in the first line.
- Keep spoken lines natural and short.
- Cut filler.
- Prefer concrete nouns, numbers, and outcomes.
- If the proof matters, use real screen recordings instead of AI-generated text on screens.

## Visual rules

- Use face-cam for authority.
- Use AI B-roll to support the point, not replace proof.
- If the offer is digital, show the real site, dashboard, Stripe page, or workflow.
- Every scene should earn its spot.

## CTA guidance

Pick one:
- DM me
- comment a keyword
- click the link
- book a call
- follow for the next part

## Quality bar

If the first 2 seconds do not create curiosity, rewrite the hook.
