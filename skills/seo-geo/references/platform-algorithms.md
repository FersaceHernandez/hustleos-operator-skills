# Platform Ranking Algorithms (2026)

## Cross-Platform Summary

| Platform | Primary Index | Key Factor | Unique Requirement |
|----------|--------------|------------|-------------------|
| ChatGPT | Web (Bing-based) | Domain Authority | Content-Answer Fit (55%) |
| Perplexity | Own + Google | Semantic Relevance | FAQ Schema |
| Google SGE | Google | E-E-A-T | Knowledge Graph |
| Copilot | Bing | Bing Index | MS Ecosystem |
| Claude | Brave | Factual Density | Brave Indexing |

## ChatGPT (200M+ users)
- Branded domains cited 11% more than third-party
- Content < 30 days old gets 3.2x more citations
- >350K referring domains = 8.4 avg citations
- Wikipedia (7.8%), Reddit (1.8%), Forbes (1.1%) top sources

## Perplexity (50M users)
- 3-layer reranking (L1 relevance → L2 traditional → L3 ML quality)
- FAQ Schema pages cited more often
- PDFs prioritized for citation
- Semantic relevance > keywords

## Google AI Overview
- 85%+ of searches show AI Overviews
- Only 15% overlap with traditional Top 10
- Authoritative citations = +132% visibility
- E-E-A-T is critical

## Copilot / Bing
- Must be in Bing index
- LinkedIn + GitHub mentions help
- Page speed < 2 seconds
- Use IndexNow for fast indexing

## Claude AI
- Uses Brave Search (NOT Google)
- Crawl-to-Refer ratio: 38,065:1 (very selective)
- High factual density preferred
- Clear structural clarity for extraction
