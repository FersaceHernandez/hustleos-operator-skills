# Proof to Content

This skill converts receipts into content.

## Trigger on

- turn this into a post
- make content from this client win
- write the thread from these screenshots
- turn this build into a reel
- how do I post this proof

## Workflow

1. Identify the proof.
2. Identify the implied claim.
3. Pull out the most surprising detail.
4. Build the content around the proof, not around theory.
5. End with a CTA that matches the proof.

## Output format

Return:
- **Angle**
- **Hook**
- **Main body**
- **Visual plan**
- **CTA**

## Rules

- Lead with the receipt.
- Use numbers when possible.
- Show what changed.
- Do not bury the proof in paragraph four.
- If the proof is weak, say what is missing.
