# AI Strategy Room

Use this skill when the user needs a real decision, not generic brainstorming.

## When to use it

Trigger on requests like:
- "Which offer should I launch?"
- "Stress test this pricing"
- "Compare these 2-3 business ideas"
- "What are the blind spots in this funnel?"
- "Should I pivot or double down?"

## Goal

Create a structured debate that surfaces:
- the best path
- the biggest risks
- what would have to be true for it to work
- the immediate next move

## Workflow

1. Define the decision in one sentence.
2. List the hard constraints, especially money, time, channel, and risk tolerance.
3. If options are vague, rewrite them into 2-4 concrete choices.
4. Force evaluation across the same categories:
   - upside
   - downside
   - speed to proof
   - required capital
   - operational complexity
   - likelihood of real revenue
5. Push for disagreement. Do not let every path sound equally valid.
6. End with one recommendation and one next action that can happen today.

## Output format

Return:
1. **Decision** — the recommended path
2. **Why this wins** — short, concrete rationale
3. **Risks** — what could break it
4. **Do now** — the next executable move

## Rules

- Kill vague strategy language.
- Prefer proof paths over prestige paths.
- Prefer revenue soon over complexity now.
- If two options are close, recommend the one that gets market feedback faster.
- Follow-up questions should reuse prior context instead of starting over.
