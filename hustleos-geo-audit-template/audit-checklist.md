# GEO Audit Checklist — The 9 Princeton Methods

Score each 1-10. Target: 7+ on all.

## Technical Foundation

- [ ] **Meta tags present** (title, description, OG, Twitter cards)
- [ ] **Schema markup** (JSON-LD — WebPage, FAQPage, Organization minimum)
- [ ] **robots.txt allows AI bots** (GPTBot, PerplexityBot, ClaudeBot, ChatGPT-User, Bingbot)
- [ ] **Sitemap.xml exists** and includes all key pages
- [ ] **Page speed < 3 seconds** (mobile)
- [ ] **Mobile responsive** (passes Google mobile test)
- [ ] **H1/H2/H3 hierarchy** clean and logical
- [ ] **HTTPS** enabled
- [ ] **Canonical URLs** set

## The 9 Princeton GEO Methods

### 1. Citations to Authoritative Sources (+40%)
- [ ] Content references credible sources (gov, edu, research papers)
- [ ] Links to authoritative external sites
- [ ] "According to [source]" format used
- Score: __/10

### 2. Statistics and Data Points (+37%)
- [ ] Specific numbers included (not vague claims)
- [ ] Data is current (within 12 months)
- [ ] Sources cited for statistics
- Score: __/10

### 3. Quotation Addition (+30%)
- [ ] Expert quotes included with attribution
- [ ] Quotes are relevant and add credibility
- [ ] Named experts, not "some say"
- Score: __/10

### 4. Authoritative Tone (+25%)
- [ ] Confident, direct language
- [ ] No hedging ("might", "could", "perhaps")
- [ ] First-person expert perspective where appropriate
- Score: __/10

### 5. Easy-to-Understand (+20%)
- [ ] Complex concepts explained simply
- [ ] Short paragraphs (2-3 sentences)
- [ ] Bullet points and numbered lists
- [ ] No unnecessary jargon
- Score: __/10

### 6. Technical Terminology (+18%)
- [ ] Domain-specific terms used correctly
- [ ] Acronyms defined on first use
- [ ] Demonstrates expertise through vocabulary
- Score: __/10

### 7. Unique Words (+15%)
- [ ] Vocabulary is diverse (not repetitive)
- [ ] Varied sentence structure
- [ ] Original phrasing (not template-sounding)
- Score: __/10

### 8. Fluency Optimization (+15-30%)
- [ ] Reads naturally when spoken aloud
- [ ] Logical flow between sections
- [ ] Transitions connect ideas
- [ ] No awkward phrasing
- Score: __/10

### 9. Answer-First Content Structure
- [ ] Direct answer in first paragraph
- [ ] FAQ format for common questions
- [ ] H2/H3 headings match search queries
- [ ] Tables for comparison data
- Score: __/10
